# CSC3206 AI Algorithm Project

An A* search implementation for multi-stop route planning.

## Setup

1. Install **Python 3.10–3.14**.
2. Install the required library:

   ```bash
   python -m pip install pygame
   ```

3. Run the program:

   ```bash
   python Assignment2.py
   ```

## Controls

- **Spacebar** — Pause/resume route finding
- **R** — Restart the process
- **Up/Down Arrow** — Increase/decrease the search speed
- **Esc** — Exit

The program displays the route cost, optimal route, and number of expanded states.
